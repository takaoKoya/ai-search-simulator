## 18.1 The one risk that gates everything else

**R11 and R12 are the risks that matter most going forward.** Every other risk in this register is about the system *as it exists today*; R11/R12 are about the system this audit recommends building next. The single non-negotiable safety rule for PHASE 1+ is: **the Planner must never gain a capability the existing human-triggered routes don't already have, and must never bypass an existing approval gate.** Every stage in `16_MIGRATION_PLAN.md` is sequenced to make that true by construction (the Planner calls the same unchanged dispatcher a human-triggered route calls), not by policy alone.
